GET and POST Methods

The following examples demonstrate how HTML forms submit data using GET and POST.

GET

Form Using GET Method

Data is appended to the URL.

<form action="process.html" method="get">
  ...
</form>
POST

Form Using POST Method

Data is sent inside the HTTP request body.

<form action="process.html" method="post">
  ...
</form>
QUESTION 2(c)

GET vs POST

Differences between the two HTTP form submission methods.

Feature
GET
POST
URL
Data is visible in the URL.
Example:
process.html?name=John&email=john@email.com
Data is not appended to the URL. It is sent in the request body.
Security
Less suitable for sensitive information because data appears in the URL.
Better for sensitive form data because values are not displayed in the URL.
Data Size
Limited because data is included in the URL.
Can handle larger amounts of data.
Typical Use
Searching, filtering and retrieving information.
Login forms, registration, loan applications and submitting data.
